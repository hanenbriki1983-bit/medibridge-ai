# GitHub Professional Plan

## Repository Standards
- Protected `main` branch
- Required PR reviews (min 1)
- Required status checks before merge

## CI Pipeline
- Python lint + tests
- Frontend build + tests
- Dependency vulnerability scan

## PR Template
- Problem statement
- Scope and non-scope
- Screenshots / API examples
- Risk assessment
- Compliance checklist (privacy/safety)

## Milestones
- M1: MVP hardening
- M2: ML improvements
- M3: RAG phase
- M4: security + DB migration
- M5: CNN pilot
- M6: clinical readiness
