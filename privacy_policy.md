# Privacy Policy (Project-Level Draft)

## Purpose
MediBridge AI processes symptom text to support preliminary triage and physician communication.

## Data Collected
- Patient display name (optional)
- Symptom messages
- Detected language
- Normalized symptom keys
- Emergency classification and reason
- Predicted disease class and confidence
- Generated doctor report
- Timestamps and technical logs

## Lawful Basis (GDPR orientation)
- Legitimate interest and/or explicit user consent (deployment policy dependent)
- Medical processing may require additional legal basis per jurisdiction

## Data Minimization
- Only collect data needed for triage/reporting use case.
- Avoid storing direct identifiers unless necessary.

## Retention
- Retain records only for defined medical/operational period.
- Apply periodic deletion or anonymization.

## User Rights
- Access request
- Correction request
- Deletion request (right to erasure)
- Restriction/objection where applicable

## Security
- Access control, encryption in transit, secure storage, and audit logs are required for production.

## Contact
- Organization must provide DPO/contact details in production deployment.
